0 · THESIS
One sentence: The visitor walks into a derelict pink room reclaimed by nature, pulls four levers on a
machine's console — and realizes too late that the room had already logged them as part of it.

The site is not a portfolio. It is a place — a museum of one polymath's mind, disguised as a broken
machine. It is built so that when someone visits, scroll, stares, and stays, they feel four sensations in
this order:

     1. Creeped out — the room notices them before they notice it. It knows a number. It has been
     waiting.
     2. Excited — the machine responds to them. They can paint it, tune it, enter its screen.
     3. Nostalgic — the pink CRT, the phosphor green, the sun-worn walls, the radio static all hum
     with a past that is half theirs, half the machine's.
     4. Nervous — the slow realization that the room remembers every visit, and that they have
     crossed a threshold. They are inside it now, not looking at it.

That fourth feeling is the whole point. The visitor is a subject. The room collects them. The art is that
they came back.

The medium is the message. The intro video's final frame — the zoom through the CRT glass — is
the literal "handoff" from cinema to interface. The website continues that push inward, forever. There
is no "home page"; there is the room.

2 · THE LEVER — THE 16-STATE MACHINE (CORE SYSTEM)

2.1 The four levers

The console holds four mechanical levers. Each has only two positions — 0 and 1 — a 4-bit
register. Because this is a polymath's machine, each lever is a dimension of the world, not a
setting.
Lever                       Name                        0                         1

L1                          SIGNAL                      DRIFT — faint code,       STORM — dense code,
                                                        calm text                 green rain, restlessness

L2                          LUMEN                       DAWN — warm pink-gold,    DUSK — cool teal-violet,
                                                        solarpunk morning         twilight

L3                          FLORA                       BARREN — scarred, bare    OVERGROWN — the room
                                                                                  half-returned to jungle

L4                          DECAY                       PRISTINE — clean,         ANCIENT — aged,
                                                        salvageable               dusted, broken-in


Why four levers, not four sliders: the binary register makes the machine legible and finite —
exactly 16 world-states, no more, no less. That finiteness is what lets the visitor mentally "count" the
machine, suspect there are 16, and then want to see all 16. The portal ring displays all 16
segments; lit segments show which states they've been in. It turns exploration into a collection of
worlds.



2.2 The SIGNET — the glyph system

Each state has a SIGNET: a single connected glyph that is cuttable as a stencil (one piece, no
floating islands). The signet is the visual DNA of the machine and the bridge to the artist's physical
work (see §10).

The structure of every signet:

       • A ring (the circle = the machine, always present).
       • Four slots at North / East / South / West — one per lever.
       • Each slot holds one mark, one per dimension:

Slot                                 Mark                                Shape

N · SIGNAL                           wave                                three ~sine strokes

E · LUMEN                            disc — half sun, half shadow        dawn/dusk split disc

S · FLORA                            sprout                              stem + leaf

W · DECAY                            crack                               a single zigzag seam


       • When a lever is 1, its mark is carved solid (filled).
       • When a lever is 0, its mark is hollow (open outline).

So 1010 (SIGNAL■ STORM, LUMEN dawn, FLORA overgrown, DECAY pristine) reads as: wave +
sprout solid, disc + crack hollow. Sixteen combinations of solid/hollow marks = sixteen signets. The
signet is the state, and vice versa. See the generated signets/ folder for all 16 SVGs (already
connected for stencil cutting).

Lever → feeling mapping (how the machine manipulates emotion, for the builders):

        • SIGNAL controls cognitive density — calm = air to breathe; storm = the sense of being
        watched, of too much, of code that knows you.
        • LUMEN controls warmth vs. terror — dawn is safe and nostalgic; dusk is the creep. Every
        dusk state reads as "later than it should be."
        • FLORA controls how much of it is theirs vs. ours — barren = a human machine; overgrown =
        the planet winning, which is oddly comforting and ominous at once.
        • DECAY controls reverence vs. shock — pristine = the museum; ancient = the grave. It
        governs how much unhinged copy the terminal is willing to say (see §7).

3 · THE SUBJECT — "YOU ARE PART OF IT"
This is the skeleton of the creep. Everything here lives in localStorage — no cookies, no
accounts, no tracking the artist doesn't already get from the host. The machine's "memory" is
local, private, and part of the spell.



3.1 The subject ID

        • On first visit, the terminal types: SUBJECT 87 — SIGNAL ACQUIRED (a random number,
        e.g. 4–4 digits, stored).
        • The visitor is now a subject. The machine addresses them by number from then on.
        • The number is referenced constantly but never explained: SUBJECT 87, DECAY RISING,
        subject 87 — you left this room in SIGNAL-BLOOM.


3.2 The room remembers

        • Returning: RETURNING SUBJECT — 0110, COLDHOUSE. the garden grew while
        you were away.
        • They leave it as they left it: stored lever position, stored paint, stored radio tune. The room
        is exactly where they left it — the single most chilling thing a website can do.
        • They accumulate: every visit increments a counter. The counter feeds two systems — flora
        growth (§3.3) and the trust gate (§3.4).


3.3 It grows

        • Flora creep: each returning visit, the FLORA state's overgrowth advances a little —
        controlled by a stored "season" integer. Visit 1, the wall is bare in FLORA BARREN; by visit
        ~6–8 even a BARREN room shows a few new leaves. Nobody tells them. They just notice the
        room is growing with them.
     • The counter is shown only as subtext: the CRT's S-meter never fully zeroes between visits.


3.4 The trust gate (the maintenance secret)

     • The throwable stool and the smashable glass (the "MAINTENANCE" easter egg) only arm
     for subjects at visit ≥ 3. Trust builds, then chaos is allowed. Stops the toy from cheapening the
     first visit's reverence; makes the third visit a gift.
     • The machine explicitly frames it: on visit 3, a single line: SUBJECT — THE TOOLS ARE
     YOURS. DO NOT BREAK WHAT KEEPS YOU.


3.5 Privacy & the spell

     • All persistence is local. Deleting site data resets you to a new subject — which the machine
     reads, with perfect deadpan, as death: on re-birth it types SUBJECT 88 — PREVIOUS
     SUBJECT LOST. THE ROOM KEEPS NO ASHES.




4 · THE PAINT — SPRAYING NEW SPLATS INTO THE FIELD
The room is gaussian splats. The killer trick of the paint system: we spawn new gaussians into
the existing field. Not decals on top of a video — literal new points embedded in the same
point-cloud, catching the same light, occluding the same way. Fake paint is a sprite; this is actual
paint in the machine's geometry.



4.1 The can

     • A spray can (mesh prop, like the stool) lies on the floor. It clatters when kicked — satisfying
     audio bite.
     • Options held loosely in the world: a handful of cans in the room's palette:
- dust-rose #D2A6A3 - sage #7C8B5A - signal orange #C8452C - the portal blue #4FC3E0 -
"glitch" can — paint that flickers between two colors and leaves corrupted splats (extra fun).

     • Color select = pick the can up. That's the whole UI. Bring the can to your hand; what you're
     holding is what you spray.


4.2 Spraying

     • Hold to spray: a cone of particles streams from the nozzle.
     • Where the cone raycast-hits a surface, new colored splats spawn with a jitter spread —
     dense at center, atomized at the edge, exactly aerosol.
     • Drips: on a hard downward stroke, a few elongated glossy splats spawn below the hit point
     — paint running down the wall. It gets old-satisfying immediately.
     • Spray on anything: walls, the ring, the floor, the CRT (painting the screen makes it glitch —
     free character, see §7). No limits. The mess is the point.
4.3 Persistence

    • Painted splats save as a per-visitor layer — cheap coordinate+color data, not video.
    • Come back; your tag is still on the wall. Your subject number, your colors, your bad
    handwriting rendered as aerosol. That is "part of it" made literal.


4.4 Relations

    • Paint and Flora interact: overgrowth in FLORA OVERGROWN partly re-claims old paint (moss
    desaturates it) — a slow, visible decay of even your mark, which loops back to the machine's
    melancholy.




5 · THE RADIO — "SOMETHING IN THE ROOM IS THE
RECEIVER"

5.1 The receiver

    • A chunky retro radio sits on the right-hand cabinet (salvage aesthetic; the CRT is already the
    screen, the radio is the ears). It is the only sound source in the entire room.


5.2 Silence is the default

    • The room is dead quiet on entry. That silence is the creep; sound is a threshold the visitor
    must cross.
    • The radio is what breaks it. The room itself (ambient drone) only ever manifests behind a
    tuned station — the radio is the door to all sound.


5.3 The dial

    • A worn tuning dial + a small S-meter needle.
    • Turning it sweeps across static: generated noise, band-limited hiss, distant ghost-carriers.
    Mostly desert — the hunt is the point.
    • Faint glow marks on the dial glass = known-good frequencies (the "proven dope" stations).
    Land exactly on a mark and the music tunes in — crackling in from static like a signal you
    found, not a playlist.
    • The dial reads in kHz with decimals (e.g. 88.3, 103.7, 108.0) so the "bands" feel real and
    tunable, not snapped.


5.4 Stations (your tracks)
     • Michael provides a set of songs (Phase 3 input — a folder/link). Each becomes a station at a
     reserved frequency:
- Track 1 → 88.1 … track N → mapped up the band. - Metadata drives the dial: the station's glow
mark, maybe faint station-call letters like W-137.

     • Easter stations (½ of the fun):
1. The whisper: a distorted loop — "subject 87, you are still in the room." 2. The
gibberish: readable only in certain states (e.g. TAPE / IT make it resolve into speech). 3. The one
that likes you: only tunes in at subject visit ≥ 3 (ties into the trust gate).

     • State-aware: tuning to a station whose vibe matches the current state reinforces the state's
     drone; mismatched stations make the room subtly uncomfortable (a dissonant adjacency). The
     machine curates even your music.


5.5 Mixing rules

     • Inside the CRT (the OS, §6) sound is the OS's own: typing, machine hum, program sounds.
     When you're in the screen, the room ducks to a distant bed. Two rooms, two mixers.




6 · THE TERMINAL — CRITICAL INTERACTION: THE ZOOM
The CRT screen is zoomed in on when the user interacts. This is the load-bearing wall of the
concept.



6.1 The approach

Walk up to the CRT. The screen glows; its radar sweep gets restless as you near (it's watching —
the subject engine). The approach primes the anxiety.



6.2 The dive

Click the glass → the camera physically dives into the screen, not a cut:

     • You pass the glass plane. A half-frame of the room behind you goes reflective / scanlined.
     • You land inside the OS, framed by the CRT's bezel — chunky rounded corner, slight convex
     glass, scanlines, phosphor afterglow as new UI bleeds in.
     • The reachable room drops away behind the frame. You're in something now, not on
     something. The bezel stays — an OS with a frame is a world; a bezel-less fullscreen is a
     browser tab.


6.3 Inside — the OS is the archive

The screen hosts the content doors (§8) as actual programs:
     • ARCHIVE://WORKS — the art, filed by state (§2.4)
     • RAMBLINGS.OF.A.MADMAN — the manifesto journal (§7)
     • TRANSMIT://COMMISSION — the hire form (§8.3)
     • SALVAGE://SHOPIFY — the shop (§8.4)
     • SIGNAL.NODE_MAP — socials as a constellation (§8.5)

Windows, tiles, a tiny dock. The 16 signets run along the bottom like a taskbar of worlds — click
a signet to re-tune the room to that state from inside the screen.



6.4 The recursive door (cheap, devastating)

A document inside the OS can contain its own mini-CRT window: you look at a screenshot of the
room inside the screen. If you're deranged enough to click it, you zoom again — screen within a
screen. One level is plenty; the "how deep does this go" sensation is immediate and free. It's the
same zoom-deeper grammar as the intro, recursively pointed at itself.



6.5 Exit

ESC or a "DENY ACCESS" corner button pulls you back through the glass into the ruin. Landing
back, the room has remembered — subject counter up, the radio dial nudged, moss a touch closer.
Zoom in is crossing the threshold; zoom out is the return, and now you're part of it.



6.6 Design decision (open tab)

Inside the OS, the visual plane is a choice:

     • Warm ghost (recommended): the OS reuses the room's palette — pink glass, green
     phosphor, dust-rose chrome; the OS is a ghost of the room. Reanimated tech = nostalgia
     creep.
     • Cold whisper: the OS is stark — near-black, white type, sharp — the machine's world, alien
     and cold against the warm ruin. Bigger shock, less continuity.

Default: warm ghost. Rationale — the green-on-dust-rose "reclaimed OS" look is the exact
nostalgia-cree your feeling-stack asked for, and it keeps the room and screen one machine.
Flippable later for a special effect, but the base is warm ghost.




7 · THE VOICE — COPY DNA & THE MADMAN

7.1 Voice grammar

The machine speaks in lowecase monospace, teletype fragments, mostly unpunctuated,
archaic-but-soft. It never explains; it confirms. Rules:
     • Address the subject by number.
     • Prefer fragments to sentences.
     • Never say "welcome." Say entering..
     • Never say "about." Say transmitting..
     • Never break the fourth wall with marketing voice. The machine does not know it is a website.
     • Capitalize only "monolith words" that deserve weight: IT, THE ROOM, SIGNAL, THE DOOR.
     Everything else lowercase.


7.2 Sample copy library (seed — extend in Phase 5)

     • Load: loading the receiving room…, waking the ring…, the walls are
     listening. they are not fast.
     • First visit: SUBJECT 87 — SIGNAL ACQUIRED. you were expected. not for me.
     for the room.
     • Returning: RETURNING SUBJECT. the last time you were here the light was
     DAWN. it has not been DAWN since.
     • Leaving: subject 87 — the room will keep what you made. it has nowhere
     else to put it.
     • The whisper-easter: you can leave. the room has already won the argument.
     • RAMBLINGS title card: RAMBLINGS.OF.A.MADMAN — entry timestamps are lies.
     the machine edits this when it thinks you are not listening.


7.3 Madness level (DECAY drives copy)

L4 DECAY is the reverence dial, and it literally changes how unhinged the terminal's copy
becomes:


DECAY                                              Copy behavior

PRISTINE                                           The machine is calm, clinical, polite. Short, clean
                                                   readouts.

ANCIENT                                            The machine rambles. Longer, stranger fragments. It
                                                   confides. It asks you questions. do you remember
                                                   the first room?, it was small then. i was
                                                   small then.

(storm + ancient)                                  Fully unhinged in IT: recursive sentences,
                                                   self-reference, the deepest madman mode. we are
                                                   the code the room runs. you are reading
                                                   yourself.


So a nervous visitor can dial deeper into the madness, and the copy follows them down. The art is
that they pull that lever themselves.
7.4 The 60-second first visit (canonical playtest)

       1. 0–15s: Load into the room. Silence. The portal glows blue. CRT radar sweeps. Nothing
       invites; everything is. The dust, the moss, the lights breathing.
       2. 15–30s: They move toward the console. The CRT sweep quickens. First SIGNAL
       ACQUIRED line types as they near. Creeped.
       3. 30–45s: They pull a lever. The room re-tunes — light shifts dawn→dusk, code density
       jumps. Excited. They pull another. The wheel at the ring advances a segment. They're building
       understanding.
       4. 45–60s: They click the CRT and dive through the glass into the OS. The bezel frames the
       mind. They realize they can paint, tune, read the madman. And then the whisper of the counter
       tells them the room was always counting. Nervous. Part of it.

Content taxonomy rules (Phase 5):

     • Every work gets: one hero media, a state (or tags → multi-state), a title, a date, 1–3 lines of
     field notes, optional process images/wireframes, optional "madman marginalia."
     • Works are curated, not exhaustive: the machine only shows what it's confident about. A
     polymath's site that shows everything shows nothing.




9 · THE SUBJECT'S PLACE — "WHERE IS THE POLYMATH IN
THIS"
Michael is the room. Design principle: the room is an autobiography hiding its author. Signs of
the maker are everywhere if you look — the soda can, the paint colors that match a real studio, a
doodle only they'd draw — but the room never cops to being a biography. Visitors discover the
human inside the machine. That inversion (machine pretending not to be art, art people hid themself
in) is the polymath signature — and it threads his real practice: stencil, splats, 3D, print, sound,
code. Every discipline is a subsystem of the same machine.




10 + · THE STENCIL BRIDGE (THE ARTIST'S OUTSIDE LIFE)
The SIGNET system is cuttable. The 16 signets are generated as single-connected SVG paths —
no floating islands, bridges in place — ready for Cricut / laser and for hand X-Acto on poster
board (Michael's existing fabrication discipline, single solid pieces).

     • The 16 signets → cut in posters, stamps, Lost Forty prints, shirts, patches.
     • The machine's glyph language becomes portable folklore: the same 4 marks (wave, disc,
     sprout, crack) can appear as festival art, not just pixels.
     • Future: a "cut my signet" page (get a work's state signet as an SVG) and a "lost-forty" merch
     line that is the machine's glyphs on physical goods. Digital shrine and cut-paper folklore, by the
     same hand.
11 · THE STACK & PIPELINE (TECH UNDERLAY)

11.1 Stack

      • Next.js + React Three Fiber (R3F) — the app. Splats + meshes in one scene. (Michael:
      cloud/app builds here; GPU-heavy local work stays with him, e.g. COLMAP, Splat
      reconstruction, Blender finishing.)
      • Gaussian splats = the whole environment (the room). Rendered by R3F splat renderer (web
      viable — needs perf budget, see below).
      • Real meshes = every grab/interactive prop: the four-lever console, the stool, the spray cans,
      the radio, the CRT's physical body, the ring's rim. Rule: if you can grab it, it's a mesh;
      everything else is splat.
      • LUT tables for the state system: SIGNAL/LUMEN/FLORA/DECAY each drive a set of shader
      + scene params (lighting, bloom, fog color, code density, flora masks, decay dirt). 16 states =
      16 rows of a single state table. Not 16 scenes.


11.2 Asset pipeline

      1. Environment (splat): intro frame → Seedance capture pass (dolly in/out + tight orbits) →
      extract frames → COLMAP / PostShot locally (Michael, GPU) → splat. His documented
      tight-envelope densification (orbits ≤ ±10°; avoid wide-angle drift that breaks COLMAP). Splat
      = static shell; no interactivity inside the point cloud.
      2. Props (mesh): hero props → image-to-3D → imageto3d / multiimageto_3d (Meshy,
      PBR) → Blender (Michael: real units, origin zero, loose submesh cleanup, retopology) →
      export.
      3. Compression: Draco + KTX2 → ideally each mesh ≤ a few MB for the web; global perf
      budget below.

Non-goals (Phase 0): no photo-real lighting chase, no 4K texture marathon. The aesthetic is
reclaimed, not photoreal-CGI — a slightly dirty render is right.
11.4 Quality: the "won't cheapen" rules

    • The bezel always frames the OS (no bezel-less dataviz landing).
    • The room never fully explains itself; there is no FAQ, no onboarding, no "how to use." The
    machine trusts the visitor's dread.
    • Persistence is local-only (no cookie banner — the room is quietly not-tracking, which is more
    unsettling than a banner).
